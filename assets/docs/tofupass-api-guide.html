Use the TofuPass API

Generate friendly passwords and passphrases from a tiny open source API. Responses are plain text for generation endpoints and JSON for discovery and stats.

Last updated May 27, 2026

Source github.com/Tofu-Water-Drinker/tofupass-api
Base URL https://tofupass.com/api
Authentication None
Generation type text/plain
Language default English, code en

GET /api/password

Returns one server-side generated readable password. The current API password format is two friendly words, one special character, and a two-digit number. This endpoint is separate from the web generator's Soft, Firm, and Extra Firm recipes.

ParamDefaultNotes
langenOptional supported language code.
 
curl https://tofupass.com/api/password
# -> !HappyTiger83

fetch('https://tofupass.com/api/password')
  .then(res => res.text())

GET /api/passphrase

Returns a hyphen-separated passphrase made from unique words in the selected word list.

ParamDefaultNotes
count4Integer from 4 to 30.
langenOptional supported language code.
 
curl "https://tofupass.com/api/passphrase?count=6&lang=fr"
# -> ocean-lanterne-sourire-jardin-cuivre-lune

GET /api/languages

Use this endpoint to build language pickers or validate client-side settings.

curl https://tofupass.com/api/languages
# -> {"default":"en","supported":["en","es","pt","fr","de","ja","zh-cn","ar","id","hi","ru"]}
enesptfrdejazh-cnaridhiru

GET /api/stats

Returns in-memory counters. They reset when the server restarts and do not contain personal data.

curl https://tofupass.com/api/stats
# -> {"generated_passwords":1234,"generated_passphrases":567,"total_api_calls":1801}

Rate limits and errors

The live generation endpoints allow 1 generation request per second, a burst cushion of 10, and 1,000 generation requests per hour. Requests above those limits return a retry hint.

StatusWherePlain-text bodyUseful headers
200All endpointsGenerated value or JSON payloadContent-Type
400/api/passphrasecount must be between 4 and 30None required
429Generation endpointstoo many requests; please slow downRetry-After, X-RateLimit-Limit, X-RateLimit-Remaining-Hour

API privacy

Generated passwords and passphrases are created in real time with Node's crypto.randomInt. TofuPass does not log generated secrets, persist them to disk, or transmit them beyond the immediate API response.
